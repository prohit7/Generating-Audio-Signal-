
# Generating Audio Signals

A collection of C programming experiments focused on digital signal generation, audio fundamentals, and PCM data handling.

This repository documents my learning journey into digital audio processing through hands-on C programming.

## Projects

### 1. C Sine Wave Generator

A C program that generates a 440 Hz sine wave, converts it into signed 16-bit PCM samples, and writes the samples to a RAW audio file.

**Specifications:**
- Language: C
- Sampling rate: 44,100 Hz
- Signal frequency: 440 Hz
- Duration: 2 seconds
- Output: RAW PCM audio

**Technologies:** C, GCC, PCM, Audacity
